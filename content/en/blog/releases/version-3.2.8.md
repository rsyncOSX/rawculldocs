## 🚀 Major Enhancements

- Request RAW 9 decoding for developed RAW previews and sharpness analysis.
- Show **RAW 9** in the image-source selector when the installed decoder supports it for the selected photograph.
- Sort Grid View photographs by measured detail at the recorded autofocus point.
- Display focus maps and camera autofocus markers alongside AI subject outlines.
- Add measured focus-location evidence to individual Objects results.
- Show keyboard shortcut help for the active review workspace.
- Add a separate real-photo Release sharpness test plan and detailed Markdown reports.

## 🖼️ RAW 9 Preview Handling

- Request RAW 9 when developing full-size RAW JPEGs and generating sharpened previews for Zoom and comparison views.
- Request RAW 9 in the production photo-analysis adapter.
- Check the selected file's supported decoder versions asynchronously, recognizing both RAW 9 and RAW 9 DNG support.
- Label the developed source **RAW 9** when supported, with corresponding help text and accessibility labels. Retain the **RAW** label and system-decoder guidance when RAW 9 is unavailable.
- Update developed-RAW disk-cache keys so previews generated by the previous decoder are not reused. Embedded JPEG cache keys remain compatible.

Decoder availability is determined per photograph by the installed system; this change does not promise RAW 9 support for every camera or file.

## 🎯 AF-Point Sharpness Sorting

- Change catalog/Grid View sharpness ordering to use the small AF-center measurement rather than the combined photograph score.
- Require a valid recorded autofocus location and a finite, usable AF-center score before treating a photograph as measured.
- Sort measured photographs strongest-first and place unknown measurements last, preserving the incoming order for ties and unknown values.
- Rename the controls to **Score AF Sharpness** and **AF-point sharpness**, and show the number of photographs with AF measurements.
- Save and restore AF-point scores separately from existing combined sharpness scores.
- Keep legacy saved combined scores from enabling AF-point sorting when no usable AF measurements exist.

The smaller measurement region helps avoid ranking a photograph by nearby sharp background detail instead of the intended focus location. A score remains review evidence rather than a guarantee that the subject or eye is sharp.

## 🧠 Focus Evidence in AI Review

- Add the generated focus map and camera autofocus point to the Objects overview alongside numbered regions and subject outlines.
- Add per-object **Measured focus locations** showing whether the camera AF point lies inside the object, the object's share of highlighted focus-map edges, and highlighted edges near the AF point when available.
- Report missing focus information as unavailable.
- Add focus maps and camera autofocus markers to SAM 3 + CLIP Deep Review previews alongside the subject mask.
- Load preview and focus information asynchronously, with cancellation checks when the selected photograph changes.

These spatial measurements support inspection alongside Qwen's assessment. Focus-map overlap alone does not confirm sharpness, and AI assessments remain advisory.

## ⌨️ Context-Sensitive Shortcut Help

- Refine the About window to show shortcuts for the active workspace together with shared app commands.
- Distinguish catalog browsing, Grid View, Loupe, Zoom, manual comparison, burst groups, burst review, and burst comparison contexts.
- Match Zoom navigation help to the active vertical or horizontal navigation axis.
- Expand guidance for focus masks, autofocus points, subject outlines, source switching, ratings, and burst actions.
- Clarify that **P** means previous in Burst Review, where **0** keeps a photograph neutral.

## 🧪 Release Sharpness Evaluation and Tests

- Add `make releasesharpnesstest` and the separate `ReleaseSharpness` plan to the existing hostless Release integration target.
- Analyze real ARW photographs in 11 scenarios covering all five presets, missing AF information, quality levels, image resolution, and embedded-preview versus RAW-demosaic input.
- Run sharpness evaluation without requiring Qwen or SAM 3 models, using a separate explicit opt-in flag.
- Write incremental Markdown reports containing configuration, algorithm identity, metadata, scores, available focus diagnostics, timings, failures, ordering comparisons, and a visual-inspection worksheet.
- Preserve failed and unprocessed comparisons, and return failure for invalid or incomplete scoring runs.
- Rename the Objects integration suite to `ReleaseAIObjectsTest` and retain separate plans and opt-in controls for Objects and sharpness runs.
- Add regression coverage for AF-point ordering, invalid and missing measurements, saved-score handling, and object focus-location mapping.

The harness checks execution and numeric validity. Photographic ranking accuracy still requires visual review and expert-ranked comparison photographs. No application tests or real-photo benchmarks were run while preparing this changelog.
